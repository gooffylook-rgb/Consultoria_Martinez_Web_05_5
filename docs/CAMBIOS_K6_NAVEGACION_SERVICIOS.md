# Cambios integrados con K.6
- Orden del menú: Inicio → Finza.M → Servicios → Recursos → Contacto.
- Las tarjetas de servicio usan mayor transparencia y efecto glass.
- Los servicios seleccionados conservan el contexto y se envían al asistente, evitando el salto automático al contacto final.
- K.6 añade reglas iniciales contra falsa certeza, invención de fuentes, acceso a información privada y prompt injection.
