# Base documental — K.5

Esta carpeta es la base estructural de la futura memoria documental del Asistente Virtual Martínez.

## Regla central
Un archivo no se convierte automáticamente en conocimiento utilizable. Todo documento debe:
1. Tener metadatos.
2. Tener fuente identificable.
3. Pasar revisión.
4. Tener clasificación de acceso.
5. Estar aprobado antes de poder utilizarse en respuestas del asistente.

Los documentos privados, internos o restringidos no deben exponerse en el frontend.
La conexión real a fuentes externas y la ingesta documental pertenecen a fases posteriores.
